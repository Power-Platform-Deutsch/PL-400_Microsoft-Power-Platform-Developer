Solution Types

Unmanaged Solutions

Used during development

Editable components

Source of truth for customizations

Managed Solutions

Used for distribution

Read-only components

Deployed to non-dev environments

Solution Components

Solutions can contain:

  • Tables and columns
  • Canvas and model-driven apps
  • Cloud flows
  • Custom connectors
  • Environment variables
  • Site maps, forms, views

Note: Reference data is NOT included!

Environment Variables

Make apps and flows configurable across environments

Support different values in dev, test, and production

Participate in full ALM process

Data types: Text, JSON, Decimal, Yes/No, or Secrets

Best Practices

  • 🚫 Don't use "Include all components" option
  • 🔗 Resolve dependencies before deployment
  • 📋 Run solution checker regularly
  • 🔀 Use source control for solution files
  • 🧪 Test in non-production environments first
  • 📊 Monitor solution history for errors

Common Deployment Errors

  • Missing dependencies
  • Conflicting solution imports
  • Existing holding solution
  • Component required by other solutions
  • Environment variable values not set
