Choosing the Right Azure Integration

  • Logic Apps - Workflow orchestration across systems
  • Service Bus - Decouple transactional systems, point-to-point communication
  • Event Hubs - Process streaming data at scale
  • Event Grid - Publish and subscribe to events
  • Webhooks - Send event data to external HTTP endpoints
  • Azure Functions - Serverless compute for custom APIs

Azure Functions Hosting Plans

Consumption Plan

Default plan, scales automatically, pay only when functions run (5-10 min timeout)

Premium Plan

Pre-warmed workers, more powerful instances, VNet connectivity (no max timeout)

Dedicated Plan

Runs within App Service plan, best for long-running scenarios

Webhooks vs. Azure Service Bus

  • 🔄 Service Bus - Asynchronous, queued requests, multiple subscribers
  • 🌐 Webhooks - Synchronous/Asynchronous, HTTP endpoint availability dependent
  • 🔐 Authentication - Service Bus uses SAS, Webhooks support headers/query strings
  • ⚡ Use Service Bus for high-scale async processing with multiple subscribers
  • 🎯 Use Webhooks for synchronous processing or existing Web API endpoints

Change Tracking Implementation

  • ✅ Enable on table metadata (Track Changes flag)
  • 🔍 Retrieve changes using OData delta links
  • ⏰ Tokens expire after 30 days by default
  • 🔄 Store token for subsequent requests
  • 📊 Change types: NewOrUpdatedItem, RemoveOrDeleted
  • ⚡ Efficient data synchronization for external systems

// Use alternate key (accountnumber) to identify an account var account = new Entity("account") { KeyAttributes = new KeyAttributeCollection { {"accountnumber", "MIC-12345"} } }; account["name"] = "Microsoft"; account["creditlimit"] = new Money(100000); var request = new UpsertRequest() { Target = account }; var response = (UpsertResponse)service.Execute(request);

When to Use Which Integration

  • 🏗️ Service Bus - High-scale async, multiple subscribers, centralized governance
  • 🔗 Webhooks - Synchronous processing, existing APIs, immediate operations
  • 📊 Change Tracking - Data synchronization with external systems
  • 🔑 Alternate Keys & Upsert - Inbound integration from external systems
  • ⚡ Azure Functions - Offload complex logic, build custom APIs
