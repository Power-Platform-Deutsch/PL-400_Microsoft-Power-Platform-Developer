Table Types in Dataverse

Standard Tables

Predefined tables for common scenarios

Examples: Account, Contact, Lead

Custom Tables

Created to meet specific business needs

Fully customizable structure

Activity Tables

Track interactions with time dimensions

Examples: Email, Phone Call, Task

Virtual Tables

Connect to external data sources

No data replication required

Column Data Types

Text Types

Single line of text

Multiple lines of text

Email, URL, Phone formats

Numeric Types

Whole number

Decimal number

Currency

Choice Types

Option sets (single select)

Multi-select choices

Yes/No boolean values

Special Types

Lookup (relationships)

Customer (polymorphic)

Image and file attachments

Calculated vs Rollup Columns

Calculated Columns: Computed on retrieve using Power Fx formulas

Rollup Columns: Aggregated from related records (sum, count, etc.)

Both are read-only and not audited

Relationship Types

One-to-Many (1:N)

Parent-child relationship

Lookup column on related table

Cascade behaviors for delete/assign

Many-to-Many (N:N)

Peer-to-peer relationship

Uses hidden intersect table

No ownership hierarchy

Connections

Informal relationships between records

Define connection roles

Flexible linking without formal relationships

Business Rules

Apply logic and validation without code:

  • Set field values and requirement levels
  • Show/hide or enable/disable fields
  • Validate data and show error messages
  • Create business recommendations

Scope: Entity, All forms, or Specific form

Security Components

Business Units

Organizational hierarchy structure

Security boundaries for data access

Security Roles

Define privileges and access levels

Assigned to users and teams

Teams

Owner teams (with security roles)

Access teams (dynamic membership)

Azure AD group teams

Column Security

Restrict access to specific columns

Field-level permission profiles

Standard Security Roles

  • 👑 System Administrator - Full access to all features
  • 🔧 System Customizer - Customization privileges
  • 🏗️ Environment Maker - Create resources
  • 👤 Basic User - Run apps and own records
  • 🚪 App Opener - Run apps only
