Client Scripting vs. Business Rules

  • Client Scripting - More powerful, supports complex logic, can access external data via Web API, works with command buttons
  • Business Rules - Simpler, form and Dataverse only, limited to columns on table/form, shows errors next to fields
  • Use client scripting when you need to reference related data, run logic on form save, implement complex conditions, or clear form values

Key Client API Concepts

  • 🔄 executionContext - Execution context for events
  • 📋 formContext - Reference to a form (replaces Xrm.Page)
  • 📊 gridContext - Reference to a grid or subgrid
  • 🌐 Xrm - Global object for operations not directly impacting form data/UI
  • 🔌 Xrm.WebApi - Methods for Web API CRUD operations
