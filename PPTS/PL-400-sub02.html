PL-400: Dataverse & Model-Driven Apps

One-Page Excalidraw Style Summary

1

Dataverse Fundamentals

🏗️ Cloud-based data platform with automatic scaling

📊 Standard & custom tables with rich column types

🔗 Relationship types: 1:N, N:N, Connections

🧮 Calculated & rollup columns (read-only)

📝 Business rules for logic without code

🔐 Role-based security with row/column level controls

2

Model-Driven Apps

🎯 Data-centric apps with responsive UI

⚙️ Component-based approach (forms, views, charts)

📱 Consistent experience across devices

🔌 Powered by Microsoft Dataverse

🔄 Multiple makers can work simultaneously

📦 Distributed as solutions

3

Form Configuration

📋 Form types: Main, Quick View, Quick Create, Card

🏗️ Structure: Tabs → Sections → Controls

✨ Specialized components: Timeline, Sub-grid, Quick view

⚡ Reference panel for related data context

⏱️ Timer control for time-based milestones

🌐 iFrames for external website integration

4

Views & Navigation

👀 Public views (managed by makers)

👤 Personal views (created by users)

🔍 Specialty views: Lookup, Associated, Quick Find, Advanced Find

🗺️ Site map defines app navigation

📊 Charts & dashboards for data visualization

📈 Power BI integration for advanced analytics

5

Command Bar

📍 Locations: Main grid, Form, Subgrid, Associated view

🔄 Actions implemented with Power Fx or JavaScript

👁️ Visibility control based on conditions

🎨 Visual designer for easy customization

⚡ OnSelect property for action logic

👥 Context-aware (selected items/rows)

6

Performance Optimization

⚖️ Balance functionality vs performance

📱 Design focused apps vs monolithic ones

👁️ Limit form columns to essential information

🔍 Optimize Quick Find columns for search

📊 Use analytics (PPAC) to identify issues

⏱️ Monitor plugin/workflow execution times

Key Connections

Dataverse provides the data foundation for model-driven apps

Forms & views determine how users interact with Dataverse data

Command bars enable actions on data in context

Security roles control access to apps and data

All customizations are packaged in solutions for deployment
