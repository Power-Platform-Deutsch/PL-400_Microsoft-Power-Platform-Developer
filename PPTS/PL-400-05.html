What are PCF Code Components?

Field Components

Custom controls for a column on a form (e.g., slider instead of text box)

Dataset Components

Custom grids to display data in tabular format (e.g., daily scheduler)

External Service Components

Components that display content from external services

Component Lifecycle Methods

init()

Initializes component instance, starts remote calls

updateView()

Called when property values change

getOutputs()

Returns values before new data receipt (optional)

destroy()

Cleans up when component is removed from DOM

PCF Advantages

  • Access to framework APIs for lifecycle management, contextual data, and metadata
  • Support for React, AngularJS and other client frameworks
  • Seamless server access through Web API
  • Access to device features (camera, location, microphone)
  • Responsive design for any screen size or device
  • Bundle all files into a single solution package

Security Considerations

  • 🔐 Components execute in user context with their permissions
  • 👥 Configure custom security roles with precise privileges
  • 🌐 Power Pages sites require Web roles and Table permissions
  • ⚖️ Consider privilege types (Create, Read, Update, Delete, etc.)
  • 📊 Determine appropriate depth (User vs Organization level)
