Authentication vs Authorization

Authentication

Verifying identity of users or processes

Microsoft Entra ID for Power Platform access

OAuth 2.0 for external systems

Authorization

Verifying access to resources

Entra ID security groups for environment access

Dataverse security roles for resource access

Out-of-the-Box Column Types

Calculated Columns

Calculated on retrieve

Limited to two-table relationships

Read-only, not audited

Formula Columns

Calculated on retrieve

Power Fx formulas

Limited currency support

Rollup Columns

Recalculated hourly

Max 10 per table

Supports hierarchical relationships

When to Use Custom Solutions

Consider custom solutions when:

  • Complex logic spanning multiple tables
  • Real-time calculations needed
  • External data integration required
  • Advanced validation rules
  • Specialized business processes

Design Principles

  • 🚫 Prefer no-code/low-code over code-first
  • ⚖️ Balance maintainability vs performance
  • 🔄 Consider upgradability and stability
  • 🧪 Leverage out-of-the-box functionality
  • 🔧 Use custom code only when necessary
