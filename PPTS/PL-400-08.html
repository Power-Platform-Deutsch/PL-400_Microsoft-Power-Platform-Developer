OpenAPI vs Azure API Management

  • OpenAPI - Distributed control, simple structure, no extra cost, lower complexity
  • Azure API Management - Centralized control, complex structure, extra security layer, usage control, additional cost
  • Choose OpenAPI for simplicity and cost-effectiveness
  • Choose Azure API Management for enterprise governance and security

OpenAPI Extensions

  • ⚡ x-ms-capabilities - Configure connector capabilities
  • 🔗 x-ms-url-encoding - Specify path parameter encoding
  • 📋 x-ms-dynamic-values - Provide dropdown options for parameters
  • 🔄 x-ms-dynamic-schema - Make parameters and responses dynamic
  • 👁️ x-ms-visibility - Control UI element visibility
  • 📝 Extensions enhance usability and functionality of connectors

Custom Code Capabilities

  • 🔄 Transform request and response payloads
  • 🔍 Access operation context and parameters
  • 📊 Log diagnostic information with ILogger
  • ⚡ Execute within 5-second timeout limit
  • 💾 Maximum size of 1MB for code
  • 🎯 Apply to specific operations or all operations
