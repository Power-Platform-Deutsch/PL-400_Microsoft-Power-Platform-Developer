Cheat Sheet – Benutzerdefinierte Updates (Canvas‑Apps)

Patch • Remove • Clear • Collections MS Learn‑Modul ↗

Schnellübersicht

Erstellen

Patch(DataSource,
      Defaults(DataSource),
      { Column1: Value1, Column2: Value2 })

Bearbeiten

Patch(DataSource,
      LookUp(DataSource, ID = 123),
      { Column1: NewValue })

Upsert (falls vorhanden → ändern, sonst neu)

With(
  { rec: LookUp(DataSource, Key = keyVal) },
  If(IsBlank(rec),
     Patch(DataSource, Defaults(DataSource), { Key: keyVal, ... }),
     Patch(DataSource, rec, { ... })
  )
)

Mehrere Sätze aktualisieren

ForAll(
  Filter(DataSource, Status = "Draft"),
  Patch(DataSource, ThisRecord, { Status: "Submitted" })
)
Achtung Delegierung: Große Datenquellen (SharePoint/Dataverse/SQL) haben Delegierungsregeln. Verwenden Sie delegierbare Operatoren/Funktionen in Filter/LookUp (z. B. StartsWith statt In, wo möglich) oder passen Sie das Design an.

Patch – Muster

Wertequellen

  • Konstanten: { Status: "Pending" }
  • Variablen: Set(varS, "Open"); { Status: varS }
  • Steuerelemente: { Qty: Value(txtQty.Text) }
  • Benutzerinfo/Formeln: { Owner: User().FullName, Timestamp: Now() }

Rückgabewert nutzen

Set(recSaved,
  Patch(Orders, Defaults(Orders), { Title: txtTitle.Text })
);
Notify($"Gespeichert: {recSaved.Title}");

Referenz auf Ziel

Patch(Orders, LookUp(Orders, ID = gal.Selected.ID), { ... })
// oder innerhalb von Galerie/ForAll
Patch(Orders, ThisItem, { ... })

Löschen – Muster

Einzelsatz

Remove(Orders, gal.Selected)

Gefiltert

RemoveIf(Orders, Status = "Obsolete")

Soft Delete (empfohlen)

Patch(Orders, ThisItem, { IsDeleted: true, DeletedOn: Now() })
Kein Undo: In Power Apps gibt es keinen Papierkorb. Absicherung durch Bestätigungsdialoge & Backups in der Datenquelle.

Sammlungen (Collections)

Basis

ClearCollect(Cities,
  {City:"Berlin", Country:"Germany"},
  {City:"Paris", Country:"France"}
)

Mit Datenquelle befüllen

ClearCollect(locOrders, Filter(Orders, Status = "Open"))

Alle löschen

Clear(locOrders)

Transformation

ClearCollect(OrdersSlim,
  AddColumns(
    ShowColumns(Orders, "ID","Title","Status"),
    "IsOld", DateDiff(CreatedOn, Today()) > 365
  )
)

Fehlerbehandlung & Feedback

Fehler abfangen

IfError(
  Patch(Orders, Defaults(Orders), { Title: txtTitle.Text }),
  Notify(ErrorInfo.Message, NotificationType.Error)
)

Validierung

If(
  IsBlank(txtTitle.Text),
  Notify("Titel ist erforderlich", NotificationType.Warning),
  Submit()
)

Bestätigungsdialog (Mini)

// Button Löschen (OnSelect)
UpdateContext({ askDel: true })

// Dialog: Ja-Button (OnSelect)
Remove(Orders, gal.Selected);
UpdateContext({ askDel: false })

Nützliche Helfer

  • UpdateIf: UpdateIf(Orders, Status="Draft", { Reviewer: User().FullName })
  • With (Lesbarkeit): With({id: gal.Selected.ID}, Patch(Orders, LookUp(Orders, ID=id), {...}))
  • Concurrent: mehrere unabhängige Aufrufe parallel ausführen.
  • Konvertierungen: Value(), Text(), DateValue(), Boolean().
  • Variablen: Set(varX, ...) (global), UpdateContext({locX: ...}) (Screen).
Tipp: Nutzen Sie // für Kommentare in Formeln und formatieren Sie längere Ausdrücke mit Zeilenumbrüchen.

Bewährte Patterns

  • Formularfrei speichern: Eingaben direkt via Patch schreiben.
  • Galerie‑Bearbeitung: Eingabefelder im Template + OnChange → Patch(ThisItem,...).
  • Bulk‑Änderungen: ForAll(Filter(...), Patch(...)) oder UpdateIf.
  • Audit: Spalten ModifiedBy, ModifiedOn beim Patch setzen.
  • Vermeide: RemoveIf(DataSource, true) in Produktion.
