1) Alternative zur Verwendung von Formularen ~6 Min.

Formulare sind praktisch, aber nicht immer passend. Wenn Daten beim Navigieren, Klicken oder in Hintergrundlogik verändert werden sollen, bieten Power Apps Funktionen zum direkten Aktualisieren der Datenquelle: Patch (erstellen/ändern), Remove/RemoveIf (löschen) und für Sammlungen Clear/ClearCollect.

Beispiel: Protokollierung bei Navigation – beim Klick auf eine Schaltfläche wird ein neuer Log‑Datensatz erzeugt und danach navigiert.
Patch(LoggingTable, Defaults(LoggingTable), {
  WhoClicked: User().FullName,
  WhenClicked: Now()
});
Navigate(NextScreen, ScreenTransition.Cover)
  • Mehrere Datensätze: ForAll für Schleifen; Collect, um Zeilen von Tabelle A nach Tabelle B zu übertragen.
  • Sammlungen sind Datenquellen: Die o. g. Funktionen funktionieren sowohl mit externen Datenquellen (z. B. Dataverse/SharePoint) als auch mit Sammlungen.

2) Die Funktion Patch zum Erstellen & Bearbeiten ~8 Min.

Datensatz erstellen

Patch(CustomerOrders,
      Defaults(CustomerOrders),
      { Region: "Americas", Country: "Canada" })

Bausteine: (1) Datenquelle, (2) Defaults(<Quelle>) für Standardspalten, (3) Objekt mit zu schreibenden Spalten.

Datensatz bearbeiten

Patch(CustomerOrders,
      LookUp(CustomerOrders, ID = 1),
      { Region: "Asia", Country: "China" })

Bausteine: (1) Quelle, (2) Zieldatensatz (oft via LookUp oder ThisItem), (3) zu ändernde Spalten.

Werte übergeben – vier typische Quellen

  • Hart codiert: { Status: "Pending" }
  • Variable: Set(varStatus, "Under Review"); { Status: varStatus }
  • Steuerelement: { Status: Dropdown1.Selected.Value }
  • Formel/Benutzerinfo: { Owner: User().FullName }
Fehlerquellen checken:
  • Alle Pflichtspalten setzen.
  • Spaltennamen exakt (Groß-/Kleinschreibung!)
  • Passende Datentypen (Zahl vs. Text etc.)

Mini‑Use‑Case: Klassen‑Check‑in

Patch(TrainingClassSignIn, Defaults(TrainingClassSignIn), {
  TrainingClass: TrainingClassDD.Selected.Value,
  FirstName: FirstNameInput.Text,
  LastName: LastNameInput.Text,
  EmailAddress: EmailAddressInput.Text,
  SignInStatus: "Attended"
})

3) Datensätze aus Datenquellen & Sammlungen löschen ~8 Min.

Einzelnen Datensatz löschen

Remove(CustomerOrders, LookUp(CustomerOrders, ID = 1))
Kein automatischer Bestätigungsdialog! Implementieren Sie ggf. selbst eine Rückfrage (z. B. Dialog mit „✅ Ja, löschen“ / „↩️ Abbrechen“).

Viele Datensätze auf Bedingung löschen

RemoveIf(CustomerOrders, Status = "Expired")

Alle Datensätze löschen

  • Sammlung leeren: Clear(MyCollection)
  • Sammlung neu füllen: ClearCollect(MyCollection, DatenQuelle) – „alles auf einmal“ beim Laden.
  • Alle aus Datenquelle entfernen: RemoveIf(CustomerOrders, true) – selten; Vorsicht!
Wichtig: In Power Apps gibt es weder „Rückgängig“ noch Papierkorb für Datenoperationen. Wiederherstellung erfolgt – falls möglich – außerhalb in der jeweiligen Datenquelle.

4) Übung: Patch‑Funktion zum Aktualisieren eines Katalogs ~3 Min.

  1. Neue leere Canvas‑App erstellen (Erstellen → Leere App).
  2. Button einfügen, per ALT ausführen, um eine Beispiel‑Sammlung zu erzeugen:
ClearCollect(CityPopulations,
  {City:"London", Country:"United Kingdom", Population:8615000},
  {City:"Berlin", Country:"Germany", Population:3562000},
  {City:"Madrid", Country:"Spain", Population:3165000},
  {City:"Rome", Country:"Italy", Population:2874000},
  {City:"Paris", Country:"France", Population:2273000},
  {City:"Hamburg", Country:"Germany", Population:1760000},
  {City:"Barcelona", Country:"Spain", Population:1602000},
  {City:"Munich", Country:"Germany", Population:1494000},
  {City:"Milan", Country:"Italy", Population:1344000})
  1. Vertikalen Katalog anbinden (Datenquelle: CityPopulations), Layout Titel/Untertitel/Text.
  2. Drei Texteingaben anlegen: tiCountry, tiCity, tiPopulation.
  3. Schaltfläche „Patch Country“ mit OnSelect:
Patch(CityPopulations, Defaults(CityPopulations), {
  Country: tiCountry.Text,
  City: tiCity.Text,
  Population: Value(tiPopulation.Text)
})
Tipp: Nutzen Sie das Copilot‑Symbol in der Bearbeitungsleiste, um Formeln erläutern zu lassen und Kommentare mit // zu übernehmen.

Quelle: MS Learn – „Übung: Patch in einem Katalog“. Ansehen ↗

6) Zusammenfassung ~3 Min.

  • Patch ist die Allzweckfunktion zum Erstellen und Bearbeiten von Datensätzen ohne Formular.
  • Remove/RemoveIf löschen Einzelsätze oder gefilterte Mengen; Clear/ClearCollect sind zentrale Werkzeuge für Sammlungen.
  • Für riskante Operationen (z. B. „alles löschen“) Bestätigung & Backup‑Strategien einplanen – kein Papierkorb in Power Apps.
