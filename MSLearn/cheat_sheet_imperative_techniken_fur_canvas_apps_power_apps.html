Cheat Sheet – Imperative Techniken in Canvas‑Apps

Kurz & praxisnah. Verweise auf das Microsoft Learn Modul „Imperative Entwicklungsverfahren verwenden“.

🧭 Entscheidungsbaum 💡 Snippets ⚠️ Stolpersteine

Entscheidungsbaum: Welche Variable?

  • Global (Set): App‑weiter Zustand, berechnete Flags, Benutzerinfos.
  • Kontext (UpdateContext): UI‑Zustände pro Bildschirm (z. B. Dialoge, Tabs).
  • Sammlung (Collect/ClearCollect): Tabellarische Daten cachen, Listen befüllen.
Merke
Variablen sind temporär pro Sitzung. Persistente Daten → in Datenquelle schreiben.

Standardwerte & Verhalten

  • Text = "", Zahl = 0, Boolesch = false.
  • Variablen aktualisieren sich nicht automatisch – nur durch Ihre Formeln oder Neustart.
  • Sammlungen sind von der Quelle entkoppelt (kein Auto‑Writeback).

Global (Set)

// App‑Start (App.OnStart) Set(varUser, User()); Set(varIsOverdue, CountRows(Filter(InvoiceEntity, CustomerNumber = ThisCustomersNumber && Status = "Outstanding")) > 3 );
Nutzen: Personalisierung, teure Filter einmal berechnen und mehrfach binden.

Einheit 3 – Globale Variablen

Kontext (UpdateContext)

// Dialog anzeigen / verstecken UpdateContext({ varShowDialog: true }); // Mehrere Werte auf einmal UpdateContext({ varCount: 1, varActive: true, varName: User().FullName });
UI‑Logik pro Bildschirm – gleichnamige Variablen auf anderen Bildschirmen sind unabhängig.

Einheit 4 – Kontextvariablen

Sammlungen (Collect)

// Cache Collect(colProjects, Projects); // Dynamisch aufbauen Collect(colColors, {Name:"Shane", FavoriteColor:"Orange"}, {Name:"Mary", FavoriteColor:"Blue"}, {Name:"Oscar", FavoriteColor:"Yellow"} ); // Ersetzen statt anhängen ClearCollect(colCustomers, Customers); // Entfernen (z. B. in Galerie‑Icon OnSelect) Remove(colCustomers, ThisItem);
Nicht delegierbar: lädt standardmäßig nur die ersten ~500 Datensätze.

Einheit 5 – Sammlungen

Bindungen & typische Snippets

  • Sichtbarkeit: Icon.Visible = varIsOverdue
  • Button aktivieren: Button.DisplayMode = If(varIsOverdue, Disabled, Edit)
  • Dialog zeigen: Papierkorb‑Icon OnSelect = UpdateContext({varShowDialog:true})
  • Dialog schließen: UpdateContext({varShowDialog:false})
  • Galerie füllen: Gallery.Items = colCustomers
  • Benutzername anzeigen: Label.Text = varUser.FullName

Übung – Schritt‑für‑Schritt

Stolpersteine & Tipps

  • Delegation beachten: Bei großen Tabellen nicht alles in Sammlungen ziehen; filtere in der Quelle.
  • Session‑Daten: Variablen/Sammlungen leben nur bis App‑Schließen. Persistenz → Datenquelle.
  • Selbst‑Referenz: Set(varCounter, varCounter + 1) für Zähler.
  • Standardwerte: Initialisiere gezielt in App.OnStart oder Screen.OnVisible.
